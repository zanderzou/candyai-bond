Identify where you are looking before deciding the media is saved. You might see a preview in the conversation, an opened item in Collections or a completed file in your device's downloads. Candy.ai help describes accessing generated items through album collections and browser confirmations when downloading.

The frames and folder represent three different places a picture or clip can appear. A visible thumbnail gives only part of the story.

## Confirm the exact item

Match the character, recognizable visual and approximate creation time. If you have two similar versions, open them separately. Choose the one with the intended crop or movement before trying to keep it.

## Open the local file independently

If a download is offered and you want to use it, follow the request for the intended file and origin. Once the browser shows completion, open the file from its saved location. Check it plays or opens correctly and includes the detail you needed. If the browser only opened a preview, look for the actual download action in the current experience.

Leave the account record intact while you verify the local copy. The resulting filename and recognizable content make it easier to locate later without relying on which message happened to show the preview.
