Inspect the existing conversation’s available upgrade option before considering a reset. Candy.ai’s Multi Mode Chat help describes an upgrade route through the chat’s three-dot menu; it also says resets switch a conversation to the newer interface, but those actions have different consequences.

The relationship-progress help states that resetting a chat starts its progression over. That makes a reset a consequential choice, not a harmless way to discover what a setting does.

## Confirm that the character supports the mode

The November Multi Mode entry describes support for standard realistic female AI characters, including characters made through Create My AI. It does not say every character category or every existing conversation exposes identical options.

If the upgrade option is absent, retain the character identity and actual menu state. Do not infer a hidden entitlement or repeatedly reset different chats to force the feature to appear.

## Review the intended action

For an original adult bookstore scene, suppose your existing thread ends with an unfinished choice between two books. Before any interface change, note the last accepted exchange and the pending choice.

Open the documented existing-chat menu route if it is available, and read the actual option and any confirmation shown. Check whether it describes an upgrade or a reset; similar placement in a menu does not make them equivalent.

The help describes new conversations as adopting Multi Mode automatically. A new conversation can be appropriate when you want a separate beginning, but it should remain distinct from preserving the ongoing bookstore scene.

## Check the settings scope

The documented defaults are under Candy.ai Settings, then Chat Settings. Those defaults apply only to supported characters. Changing them should not be assumed to affect a character where the feature is unavailable.

After an intentional supported change, inspect the actual conversation and available settings. This guide does not claim that an upgrade was performed or certify lossless transfer of an individual thread. Preserve what matters, read the current confirmation and keep a progression reset separate from an interface preference.
