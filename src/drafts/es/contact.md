# Contacto y correcciones

Para revisar una afirmación necesitamos la URL de la página, el fragmento concreto, el motivo y una fuente original que permita comprobarlo. Una tarifa que ha cambiado, una función retirada o una atribución incorrecta merecen una revisión distinta de una preferencia personal sobre el diseño.

## Estado del correo

La dirección prevista es `support@candyai.bond`, pero **el servicio de recepción todavía no está configurado**. No la utilices como vía garantizada para avisos importantes y no supongas que un mensaje ha llegado. Antes de una futura publicación se volverá a comprobar este estado.

## Problemas con el producto

No podemos acceder a tu cuenta, cancelar pagos ni borrar conversaciones de Candy AI. Para esas gestiones utiliza el [centro de ayuda oficial](https://everai.zendesk.com/hc/en-us). Esta publicación no es su servicio de asistencia.

## Información que no debes enviar

No compartas contraseñas, códigos de verificación, datos de tarjeta, imágenes privadas, chats completos o información de otras personas. Para señalar un error editorial suele bastar un extracto sin datos personales y la referencia pública correspondiente. Si se habilita un buzón más adelante, esta página explicará sus condiciones reales; no prometemos un plazo de respuesta que aún no podemos cumplir.
