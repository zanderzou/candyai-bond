# Candy AI vs Lovescape: 연속성과 기억을 구분하기

긴 대화가 친근하게 느껴져도 캐릭터 설정과 모순이 없다는 뜻은 아닙니다. 같은 가상 인물과 계속 대화하려면 Candy AI와 Lovescape의 기능 수보다 이름, 말투와 이전 사실을 유지하는 데 얼마나 개입해야 하는지 살펴보세요.

## 설정, 문맥과 저장된 기억

캐릭터 설정은 정체성과 행동의 경계를 줍니다. 최근 문맥은 그때 답변에 사용할 수 있는 정보입니다. 지속적인 기억은 나중에 필요한 정보를 다시 이용하는 문제입니다. 매번 요약을 붙이면 도움이 될 수 있지만 자동 기억의 증거는 아닙니다.

가상의 취향 두 가지와 지켜야 할 선을 하나 정하세요. 주제를 바꾼 뒤 답을 질문에 넣지 않고 취향을 물어봅니다. 바로 맞힌 답, 수정 뒤 맞힌 답과 모순을 따로 기록하면 사용자의 도움을 제품 능력으로 잘못 계산하지 않게 됩니다.

## Candy AI를 출발점으로 삼을 때

기존 캐릭터, 직접 제작과 미디어를 한 흐름에서 탐색하는 방식은 아직 선호를 찾는 사람에게 맞을 수 있습니다. 여러 도구 사이의 이동을 줄일 가능성도 있지만 외모가 마음에 든다고 말투나 이용 가능한 기능도 맞는 것은 아닙니다.

시험하는 동안 같은 캐릭터를 유지합니다. 문제가 생길 때마다 다른 인물을 고르면 연속성 대신 탐색을 시험하는 셈입니다. 텍스트에서 음성이나 이미지로 이동할 때 다시 설명한 정보, 토큰을 쓴 행동과 전체 시간을 적으세요.

## Lovescape의 방향과 제한

Lovescape는 캐릭터, 대화와 미디어의 연속성을 강조합니다. 한 가상 정체성을 차근차근 이어 가려는 사람에게 검토할 만한 방향입니다. 동시에 도움말의 기억과 일관성 제한도 읽어야 합니다. 홍보만으로 모든 대화가 완벽히 기억된다고 보장할 수는 없습니다.

실제 인물의 사진 대신 텍스트로 만든 가상의 성인을 사용하세요. 매번 이미지의 외모를 수정해야 한다면 수정 횟수와 Chips 소비를 포함합니다. 좋은 결과만 골라 보여 주고 그 전의 노력을 빼면 일상 사용의 부담을 알 수 없습니다.

## 첫 대화와 다음 방문

처음에는 답변 길이보다 말투와 경계 대응을 봅니다. 일상적인 의견 차이를 넣어 무조건 동의하지 않으면서 설정을 유지하는지 확인하세요. 미디어를 사용할 수 있다면 대화와 관련된 안전한 장면 하나만 요청합니다.

다음 방문에서는 수동 요약을 주기 전에 이전 취향을 물어봅니다. 실제 이용 빈도에 맞춰 돌아온 간격을 기록하세요. 어떤 사실이 다시 등장했는지와 얼마나 설명을 보충했는지를 나눠 적습니다. 개인 대화를 편집팀에 보낼 필요는 없습니다.

| 신호 | 기록할 내용 |
| --- | --- |
| 정체성 | 이유 없는 이름, 직업과 말투 변경 |
| 기억 | 다시 입력하지 않고 떠올린 사실 |
| 개입 | 수정 메시지와 직접 쓴 요약 |
| 미디어 | 텍스트, 음성과 이미지의 일관성 |
| 비용 | 계약 총액과 전체 과정의 사용량 |

## 장점이 될 수 있는 부분과 결론

Candy AI는 캐릭터와 미디어를 탐색하는 통합된 입구로, Lovescape는 한 정체성을 지속하는 방향으로 평가할 수 있습니다. 이것은 사용 목적에 따른 가능성이지 우리가 측정한 기억 순위가 아닙니다. 다른 계정과 설정을 하나의 보편적인 승패로 합치지 않습니다.

수정이 적으면서 목적을 달성하고 비용을 유지할 수 있는 흐름을 고르세요. 친근함은 인간의 이해나 전문 상담의 비밀 보장을 뜻하지 않습니다. 채팅, 생성물과 계정 삭제 규칙은 두 사업자에서 따로 확인하고, 가상 인물을 실제 관계나 전문 지원의 대체로 삼지 마세요.
